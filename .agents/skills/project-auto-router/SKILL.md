# Project Auto Router

Classifique automaticamente a tarefa.
Nao exija comandos com cifrao.

## 8 categorias instaladas
1. codex-antigravity-skill-policy
2. project-auto-router
3. project-layout-router
4. project-security-router
5. project-backend-router
6. project-database-router
7. project-deploy-router
8. project-review-router

## Mapa automatico
- UI/layout/CSS/HTML/design/dashboard/tela/modal/formulario/tabela/responsividade: project-layout-router.
- seguranca/auth/sessao/cookie/JWT/RBAC/XSS/CSRF/SQLi/IDOR/CORS/API/permissoes: project-security-router.
- backend/API/controller/service/repository/DTO/endpoint/regra de negocio/exception/integracao: project-backend-router.
- database/banco/schema/tabela/coluna/indice/FK/migration/SQL/query/ORM/seed: project-database-router.
- deploy/Docker/Railway/Vercel/AWS/GitHub Actions/Codespaces/logs/healthcheck/env/build: project-deploy-router.
- bug/review/refatoracao/diff/patch/pre-push/qualidade/regressao/PR: project-review-router.

Quando a tarefa cruzar nichos, combine routers. Exemplo: endpoint inseguro = backend + security + review.
