# Taste Skill

Objetivo: evitar UI generica, sem personalidade, com cara de template ou AI slop.

Regras:
- escolher direcao visual coerente com o produto
- priorizar hierarquia, espacamento, contraste e clareza
- evitar decoracao inutil
- evitar gradiente generico e glow exagerado
- criar interface que pareca produto real
- revisar estados de hover, focus, vazio, erro e loading
